GUIA DE USO
Do arquivo
ao mostrador.
1. Escolha sua imagem
Importe uma foto, uma arte ou um GIF. O app ajusta ao formato escolhido. Arraste a imagem, faça pinça para ampliar e gire com dois dedos.
2. Acerte o enquadramento
Use Preencher para cobrir a tela; Imagem inteira para não cortar; Desfocado para completar as bordas; Esticar para deformar. Quatro cantos corrige uma tela fotografada de lado.
3. Exporte ou envie
Exporte PNG para o mostrador de fotos do MActive Pro. O botão Bluetooth só envia quando a conexão e as capacidades são confirmadas. Use a resolução informada pelo relógio, não uma estimativa pelo nome comercial.
4. Preserve suas criações
Salvar no catálogo mantém a imagem e os ajustes no aparelho. Exportar projeto cria um JSON editável para backup. Desinstalar o app remove o catálogo local.
GIF e barra de saúde
A exportação GIF preserva a animação importada, dentro dos limites de memória, ou cria o traçado de ECG. Não representa batimentos reais. A importação de GIF pode ser limitada a 90 quadros; o app avisa quando isso ocorrer.
Privacidade e limites
O processamento é local, sem conta e sem envio de fotos a servidores. Arquivos até 24 MB. Imagens muito grandes são reduzidas a até 2048 px na importação. O suporte a HEIC/HEIF depende do Android. SVG não é aceito por segurança.
